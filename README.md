### 🚀 Featured Projects

#### 🎮 [Rift Analyst](https://github.com/Usokka/rift_analysis)

Data platform analyzing **20,871 professional League of Legends matches**.

* Reproducible ingestion and data-quality pipeline
* **28 documented KPIs** covering teams, players and drafts
* Comparative dashboard covering **5 leagues and 30 teams**
* PostgreSQL storage, API, CSV export and automated CI/CD
* [Live dashboard](https://usokka.github.io/rift_analysis/)

**Stack:** Python, Pandas, PostgreSQL, FastAPI, React, TypeScript, Docker, GitHub Actions

* Dataset prepared for machine-learning training across **15 traffic classes**

**Stack:** Python, Pandas, NumPy, Jupyter
